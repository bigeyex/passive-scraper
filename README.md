# Passive Scraper

A powerful, hybrid scraping tool that combines passive network monitoring with active browser automation. It bridges a React-based Chrome DevTools extension with a Python backend via WebSockets.

## 🚀 Overview

Passive Scraper allows you to collect data from websites without the need for complex, fragile crawling logic. By running as a **Chrome DevTools Extension**, it can capture and process data directly from network requests while you browse normally, or while being controlled remotely by a **Python script**.

### Key Features

- **Passive Capture**: Automatically extract data from JSON network responses matching specific URL patterns.
- **Active Automation**: Remote control your browser from Python—click, type, and extract HTML or images.
- **DevTools Integration**: High-performance monitoring integrated directly into the browser's developer environment.
- **Data Management**: View and manage captured data in structured tables within the extension UI.
- **Persistent Sessions**: Maintain state and automation across browser reconnections.

## 🛠 Architecture

The project consists of two main components:

1.  **Frontend (React Extension)**: A Vite-powered React application that resides in the Chrome DevTools panel. It listens for network traffic, handles data processing, and provides a UI for managing scraping "Plans".
2.  **Backend (Python Server)**: A WebSocket server (`PSServer`) that allows external scripts to interact with the browser extension, sending commands (JS evaluation, clicks, data retrieval) and receiving captured data.

## 📖 Getting Started

### Prerequisites

- **Node.js** (v18+) and **npm** or **pnpm**.
- **Python 3.8+**.
- **Google Chrome**.

### Backend Setup

1.  Navigate to the project root.
2.  Install Python dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3.  Start the Python companion server:
    ```bash
    python server.py
    ```

### Frontend Setup

1.  Install dependencies:
    ```bash
    npm install
    ```
2.  Build the extension:
    ```bash
    npm run build
    ```

### Loading the Extension

1.  Open Chrome and go to `chrome://extensions/`.
2.  Enable **Developer mode** in the top right.
3.  Click **Load unpacked** and select the `dist` folder generated by the build.
4.  Open DevTools (`F12`) on any page and look for the **Passive Scraper** tab.

## 🖥 Usage

### 1. Creating a Plan
Define a "Plan" in the extension UI. A plan typically includes:
- **URL Filter**: A substring to match against outgoing network requests.
- **Table Name**: Where to store the extracted data.
- **Extraction Logic**: (Internal) Processes the JSON response into rows.

### 2. Starting the Capture
Click **Start Listening** in the extension. As you browse, requests matching your filters will be captured and their data stored.

### 3. Remote Control (Python)
Use the `PSServer` to automate interactions:
```python
from python.PSServer.server import run

def my_automation(browser):
    # Remote control the browser!
    browser.run("console.log('Hello from Python!')")
    html = browser.get_html(".main-content")
    print(html)

if __name__ == "__main__":
    run(init=my_automation)
```
